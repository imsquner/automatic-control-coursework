# 资料索引与填报顺序

## 从哪一份开始

1. 先看 [课程要求](course-requirements.md)，核对封面、正文、图表、页码、文献和打印要求。
2. 从 [可编辑 Word 模板](report-template.docx) 复制自己的工作稿。将课程发给自己的任务书插入预留位置，并替换封面字段与学校指定页眉。
3. 用 [写作与验收指南](report-guide.md) 建立“小题—正文位置—图片或表格—原始材料”对应关系。七个建议图位是三张结构示意、三组阶跃响应对比和一张误差变化图。四张表是判定结果、动态指标、稳态误差和课程成绩评定表。
4. 软件运行问题先用 [环境检查脚本](../scripts/verify-matlab.ps1) 检查。该脚本运行独立的热水冷却示例。
5. 实际结果到齐后补摘要中的结果段、结论和心得。删去待填提示，更新目录，复核打印预览及正文的有效打印面。

## 核查重点

- 并列曲线应标注每条曲线的对象和单位。图题和正文使用一致的称呼。
- 第 3 章的稳态输出与第 5 章的稳态误差分别记录。数据没有支持时保留待核对状态。
- 参考文献以正文首次出现为序。提交前逐条核对正文引用与文末条目。
- 任务书、成绩评定表和普通正文承担不同功能。任务书保持课程原页，评定表保留答辩手写区域。
